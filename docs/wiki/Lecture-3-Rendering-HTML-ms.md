## Apa yang kami perolehi

- Laluan boleh memulangkan HTML, bukan hanya rentetan biasa.
- CSS sebaris seperti `style='text-align: center'` menggayakan satu elemen.
- `<img>` ialah teg yang menutup sendiri; `src` ialah alamat gambar atau GIF dan `width` menetapkan saiz.
- Gunakan tanda petikan yang berbeza di luar dan di dalam, supaya rentetan Python dan atribut HTML tidak menamatkan satu sama lain.
